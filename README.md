# HYDRA — Independent Research and Development

Public website for the HYDRA project.

## Site structure

- `index.html` — overview and entry point
- `progetto.html` — project scope and system principles
- `risultati.html` — measurements, experiments and limitations
- `metodo.html` — verification method and evidence principles
- `ricerca.html` — research directions and development status
- `aggiornamenti.html` — dated project and measurement updates
- `contatti.html` — contact information

## Shared assets

- `assets/css/site.css` — common responsive design
- `assets/js/translations.js` — existing seven-language content
- `assets/js/site.js` — language selection and shared navigation
- `assets/images/mesh.svg` — original abstract network artwork

The previous single-page version is preserved at `archivio/index-v1.html`.

The site is static and intended for GitHub Pages. Measurements are presented with their scope, configuration and limitations; retrieval metrics are not presented as answer-quality metrics.
